# Anna Heaner Site

## Deploy to GitHub

1. Create a folder named `annaheaner-site`.
2. Add `index.html`, `vercel.json`, and `README.md`.
3. Add your images to `assets/images/`.
4. Commit and push the folder to GitHub.

## Deploy to Vercel

1. Open Vercel.
2. Import the GitHub repository.
3. Deploy as a static site.
4. Vercel will serve `index.html` automatically.

## Notes

- Use the attached Swiss image as `assets/images/Swiss-image-1.jpg`.
- Add more photos into `assets/images/` and update the gallery if needed.
